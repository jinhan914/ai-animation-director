# Demo video — storyboard (target 2:45, limit 2–4 min)

Record after the demo is approved. Screen-record the live app at 1280×720;
no facecam needed. Narration is the script below, read over the actions.

## 0:00–0:15 — Hook (kinetic type on screen)

**On screen:** Director open on the Product launch preset, stage playing.
**Say:** "Every animation tool asks you to pick a library first. Director asks
you to pick nothing — you just type the script."

## 0:15–0:45 — The problem

**On screen:** Cut to the script panel; highlight the blank lines between
scenes.
**Say:** "A script is scenes. A data scene is not a headline scene, and a
formula is not a launch. Pick the wrong tool and you rebuild the whole thing.
Director reads the script, splits it into scenes, and casts the right library
for every single one."

## 0:45–1:30 — Live demo, product launch

**On screen:** Click "Direct my animation". Play the cut. Pause on scene 3.
**Say:** "Four scenes, thirty seconds. The headlines get Anime.js — kinetic
type, stagger sixty milliseconds. The launch scene gets Proton — two hundred
particles, zero render time. Every choice comes with a reason in plain words,
and the options it rejected, so you can argue with it."
**Show:** the Director's choices panel; scroll through scenes 1–4.

## 1:30–2:15 — It is not a one-trick demo

**On screen:** Click the Maths explainer preset — it fills the script box
only — then click "Direct my animation" and play scene 3. Then the same for
A short story, play scene 1.
**Say:** "Same app, different script. The maths lesson gets Manim for the
proof and Motion Canvas for the numbers. The story gets Three.js for the
stars. Nothing was reconfigured — the script did the casting."

## 2:15–2:40 — The code is the product

**On screen:** Generated code panel; click Copy code. Click Download
storyboard (.json) and show the file.
**Say:** "The code is the source of truth, not a video file. Change a word,
the cut regenerates. The generated code points at the real pipeline — Remotion
for a narrated video, Manim for maths, Motion Canvas for diagrams."

## 2:40–2:45 — Close

**On screen:** Hero, then the Devpost page.
**Say:** "Director. Type a script — it casts the animation. SLAY HACKS 2026."

## Shot list (for the edit)

1. Hero + stage playing (0:00)
2. Script panel, blank lines highlighted (0:15)
3. Full playthrough, product launch (0:45)
4. Director's choices, scenes 1–4 (1:05)
5. Maths preset (fill, then Direct), scene 3 Manim (1:30)
6. Story preset (fill, then Direct), scene 1 Three.js (1:55)

8. Storyboard JSON download (2:30)
9. Hero close (2:40)

## Notes

- Keep the cursor moving deliberately; do not wave it.
- Record the stage at 1280×720; the app is 16:9 on the stage.
